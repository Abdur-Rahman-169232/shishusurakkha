---

## 1. Purpose

This statement exists so that examiners, employers, platforms, and any later reviewer can see, without ambiguity:

1. who decided what the product is;
2. who steered every material choice; and
3. what the AI system actually did.

The AI system is **not** a co-author, joint inventor, or equal contributor of the work. It was used as a coding instrument under continuous human direction.

---

## 2. Directing role of the human principal

Abdur Rahman conceived the product, set the scope, and guided the path from an empty workspace to a deployed application. The principal specified, among other things:

- the purpose of the system (field EPI tracking for rural Health Assistants in Bangladesh);
- required features (camera scan of EPI cards, WHO/DGHS schedule, offline queue, voice reminders, DHIS2 export, dual auth);
- the move from a local Vite app to Next.js for Vercel hosting;
- GitHub publication under the principal’s account;
- production deployment on Vercel;
- that records must persist across browsers (including Incognito) in Vercel-hosted storage;
- that Neon marketplace terms would not be accepted and that Vercel Blob should be used instead;
- corrections when the live registry did not show saved children.

The principal reviewed outputs, accepted or rejected them, and instructed the next step. No material product decision was left to the AI system to originate or own.

---

## 3. Role of the AI system

The AI system’s function was **implementation under instruction**: it combined the directed requirements into source code, project files, configuration, and deployment commands.

That work included:

- generating and editing application code (React / Next.js screens, APIs, styling, and data helpers);
- assembling existing libraries and platform services into a running app;
- applying requested stack changes (Vite to Next.js; local storage to Vercel Blob);
- running local and remote commands (install, build, Vercel deploy) when instructed;
- diagnosing and patching defects identified by the principal (including the private-Blob read failure that hid already-saved child records).

The AI system did not choose the product. It did not independently decide the legal, operational, or deployment path. It combined and wrote code along the path the principal set.

## 4. How contribution is to be described

The correct description of this project is:

> **Human-directed software.** The principal defined the problem, the path, and the acceptance of results. An AI coding assistant generated and assembled source code as a tool.

The incorrect description is any of the following:

- that the human and the AI “co-created” the work in equal parts;
- that the AI is a joint author;
- that the human merely prompted while the AI “built the product” as an independent maker;
- that every line of source code is original literary expression typed by the human.

Credit for **direction, specification, selection, and publication** belongs to Abdur Rahman. The AI system is a **coding tool** used to combine those instructions into working software.
